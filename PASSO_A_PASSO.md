# IoT - passo a passo (cerca de 40 min)
1. Abra https://wokwi.com e crie um projeto **Arduino Uno** (New Project -> Arduino Uno).
2. Cole o conteúdo de `wokwi/sketch.ino` no `sketch.ino` e de `wokwi/diagram.json` na aba `diagram.json`. Clique em Start. Se algum fio ficar torto, apenas ajuste no editor (a lógica é a mesma).
3. Faça os testes T1 a T6 do README e tire prints do circuito + monitor serial. Salve em `evidencias/` com os nomes do README.
4. Preencha nomes/RM, resultados dos testes e a declaração de IA no README.
5. Crie um repositório público no GitHub com esta pasta (código, README, docs, evidências) e envie no Portal um .txt (modelo em `ENTREGA_exemplo.txt`).
